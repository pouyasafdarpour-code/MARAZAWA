# Creative web motion · MARAZAWA

کتابخانهٔ عمومی تکنیک‌های حرکت و تعامل، ثبت‌شده در ۱ نوامبر ۲۰۲۶.
این پوشه فقط دانش طراحی رابط را مستند می‌کند؛ دادهٔ کاربران، سفارش‌ها، کلیدها، پرامپت‌های اختصاصی تولید، مدل درآمدی داخلی و کد سمت سرور در آن قرار ندارند.

## مهارت‌های پیاده‌شده

- [اسکرول اینرسی و پیوند با اسکرول](inertial-scroll/SKILL.md): Lenis، چرخهٔ مشترک GSAP، حفظ رفتار فرم و منو.
- [روایت با حرکت](scroll-choreography/SKILL.md): ScrollTrigger، ظاهرشدن اجزا، پارالاکس محدود تصاویر و حرکت تیتر فارسی.
- [ذرات و هندسهٔ معماری](architectural-particles/SKILL.md): Canvas اختصاصی، نقاط، شبکه و خطوط توپوگرافی مفهومی.
- [تعامل و بازخورد](interaction-feedback/SKILL.md): واکنش مغناطیسی کنترل‌شده، عمق کارت و توقف قابل دسترس.

در صفحه‌های معرفی، حرکت بیانگر روایت است. در فرم، حساب، پشتیبانی و ورود، حرکت ملایم‌تر است و روی فیلدها، اعتبار، پرداخت یا ارسال فرم اثر نمی‌گذارد. اسکرول لمسی موبایل طبیعی می‌ماند.

## ابزارها و نسخه‌ها

در اجرای مرجع، Lenis **1.3.27**، GSAP و ScrollTrigger **3.15.0** دریافت و با SHA-512 اعلام‌شدهٔ مخزن npm تطبیق داده شدند. فایل‌ها از میزبان خود سایت ارائه می‌شوند. هنگام استفادهٔ مجدد نسخه را آگاهانه بررسی و ثابت نگه دارید.

- [Lenis: مستندات رسمی و مجوز MIT](https://github.com/darkroomengineering/lenis)
- [ScrollTrigger: مستندات رسمی](https://gsap.com/docs/v3/Plugins/ScrollTrigger/)
- [مجوز GSAP](https://gsap.com/standard-license/): مجوز اختصاصی است؛ آن را MIT معرفی نکنید و اعلان‌های مالکیت را حفظ کنید.
- [tsParticles](https://particles.js.org/): منبع تکمیلی بررسی‌شده؛ در اجرای مرجع استفاده نشده، زیرا میدان Canvas اختصاصی سبک‌تر و متناسب با روایت بوده است.

این پوشه نقشهٔ مکان واقعی، تحلیل اقلیم، طراحی سازه یا دادهٔ جغرافیایی ارائه نمی‌کند. خطوط معماری و توپوگرافی صرفاً گرافیک مفهومی‌اند.

## معیار پذیرش

محتوا بدون جلوه‌ها قابل استفاده باشد؛ توقف حرکت و ترجیح کاهش حرکت رعایت شود؛ فرم و اسکرول داخلی کار کنند؛ زیر منوهای باز، تعامل مسدود نشود؛ پنل موبایل سرریز افقی نداشته باشد؛ تب پنهان پردازش نمایشی مداوم نداشته باشد. موفقیت بارگذاری یک اسکریپت را معادل آزمون کامل همهٔ مسیرهای تجاری گزارش نکنید.

# اثر اجتماعی: از فعالیت تا نتیجه

تعداد تصاویر و تعداد بناها به‌تنهایی اثر اجتماعی را نشان نمی‌دهند. برای هر پایلوت، خط مبنا، بازه زمانی، روش ثبت و مسئول پایش تعیین شود.

| حوزه | شاخص پیشنهادی | روش ثبت |
|---|---|---|
| دسترسی | زمان و هزینه دسترسی به خدمت | خط مبنا و پیگیری با روش یکسان |
| استفاده | کاربر یکتا و ساعات استفاده واقعی | ثبت تجمیعی بهره‌بردار |
| پایداری | هزینه جاری و منابع تأمین | دفتر هزینه و تعهدات مستند |
| شمول | دسترسی گروه‌های کمتر برخوردار | داده تجمیعی و مشارکت داوطلبانه |
| آموزش | تکمیل فعالیت و کاربرد مهارت | ارزیابی متناسب با هدف برنامه |
| فضا | میزان استفاده از فضای احیاشده | مشاهده و ثبت دوره‌ای |

اهداف پیشنهادی باید از نتایج اندازه‌گیری‌شده جدا شوند. تغییر مشاهده‌شده بدون طراحی ارزیابی مناسب، اثبات اثر علّی پروژه نیست.

سوابق فعالیت آموزشی در بلوچستان و روداب سبزوار، طبق معرفی بنیان‌گذار، بخشی از زمینه میدانی مارازاواست. این بسته بدون مدارک تحویل، شمار کاربران یا نتایج مستند، هیچ پروژه‌ای را تکمیل‌شده یا دارای اثر قطعی معرفی نمی‌کند.

داده فردی حساس و تصاویر قابل شناسایی افراد بدون مجوز متناسب در مخزن عمومی قرار نگیرند. انتشار گزارش‌ها ترجیحاً در سطح تجمیعی باشد.

# فناوری و حریم هستهٔ مارازاوا

این مخزن، ویترین عمومی مارازاوا برای معرفی خدمات، نمونه‌های مجاز و پروژه‌های مستند است.

## مرز انتشار

دیتابیس، اطلاعات کاربران، پرونده‌های منتشرنشده، کد اجرایی سمت سرور، مهارت‌های اختصاصی، پرامپت‌ها، قواعد تولید و ارزیابی، کلیدهای API و جزئیات داخلی درآمد و عملیات خصوصی می‌مانند و در این مخزن منتشر نمی‌شوند.

معرفی عمومی قابلیت‌ها به معنی انتشار روش اجرایی یا اعطای مجوز استفاده از هستهٔ محصول نیست.

## آنچه می‌توانید ببینید

- خدمات و مسیر استفاده: https://www.marazawa.com/
- نمونه‌های خروجی با تفکیک نمونهٔ نمایشی و پروژهٔ واقعی: https://www.marazawa.com/projects
- داستان پروژه‌های مستند: https://www.marazawa.com/impact
- معرفی رسمی: https://www.marazawa.com/marazawa

انتشار کار کاربران تنها با رضایت آن‌ها و بررسی محتوای قابل انتشار انجام می‌شود. برای همکاری، معرفی و نمونهٔ خروجی ارائه می‌شود؛ هستهٔ اختصاصی محصول عمومی نمی‌شود.

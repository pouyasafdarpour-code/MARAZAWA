# پیشنهاد همکاری برای شتاب‌دهنده‌ها و شرکا

## هدف مشترک

تبدیل نمونه‌های منتشرشده مارازاوا به محصولی که مخاطب مشخص داشته باشد، ارزش قابل سنجش ایجاد کند و هزینه تحویل و بهره‌برداری آن روشن باشد.

## از شریک چه می‌خواهیم؟

| ظرفیت | کاربرد مشخص |
|---|---|
| سرمایه مرحله‌ای | توسعه محصول و اجرای پایلوت، مطابق بودجه مصوب |
| تیم فنی | ممیزی کد، بک‌اند، حساب کاربری، پرداخت و عملیات |
| منتور محصول و بازار | انتخاب مشتری اولیه، آزمون قیمت و فروش |
| ارتباطات | دسترسی به خریدار سازمانی و جامعه پایلوت |
| زیرساخت | محیط تست، استقرار، پایگاه داده و پایش |
| پژوهش دانشگاهی | بازبینی روش، داده و طراحی ارزیابی اثر |

## مارازاوا چه می‌آورد؟

هویت و مأموریت مشخص؛ تجربه و دسترسی میدانی اعلام‌شده؛ شناخت معماری و مدیریت شهری؛ سه نمونه منتشرشده؛ توان طراحی، ارائه و روایت پروژه. سوابق و حقوق دارایی‌ها در بررسی همکاری باید با مدارک تطبیق داده شوند.

## پایلوت پیشنهادی ۹۰روزه

| مرحله | تحویل | شرط عبور |
|---|---|---|
| روز ۱ تا ۱۵ | انتخاب یک محصول، مخاطب، دامنه و خط مبنا | توافق کتبی درباره مسئله، داده و مسئولیت‌ها |
| روز ۱۶ تا ۴۵ | ممیزی فنی و نسخه قابل آزمایش | گردش اصلی قابل استفاده و رفع مشکلات حیاتی |
| روز ۴۶ تا ۷۵ | آزمایش با کاربران هدف و ثبت هزینه/رفتار | داده واقعی درباره استفاده، کیفیت و تمایل به پرداخت |
| روز ۷۶ تا ۹۰ | گزارش و تصمیم ادامه، اصلاح یا توقف | توافق بر اساس شواهد، نه صرفاً رضایت از ظاهر |

تعداد کاربران، بودجه و آستانه موفقیت در شروع پایلوت تثبیت می‌شوند. پیشنهاد، تعهد اجرایی یا قرارداد سرمایه‌گذاری نیست.

## چارچوب قرارداد

شتاب‌دهی و سرمایه‌گذاری، خرید خدمت و اسپانسرشیپ سه شکل متفاوت همکاری‌اند. سهم، حقوق مالکیت فکری، مجوز استفاده، محرمانگی، بودجه، مراحل پرداخت و مسئولیت پروژه‌ها باید برای شکل منتخب مشخص شوند. صرف انتشار این صفحه هیچ سهم یا حق مالکیتی منتقل نمی‌کند.

**قدم بعدی:** جلسه ۳۰دقیقه‌ای برای مرور دمو، انتخاب یک پایلوت و تعیین مسئول بررسی فنی و تجاری.
